## About

I'm a software engineer focused on backend development, API design, system integrations, and data-driven applications. I've worked in backend since 2018 and currently work as a Software Engineer at **Grupo Boticário**, after roles at Grupo FCamara, Loggi, Kunumi, Seedz, and Montreal Informática.

My core stack is **Node.js**, **TypeScript**, and **NestJS**. I work across relational and NoSQL databases, build full-stack web applications when needed, and care about maintainable architecture, automated testing, observability, and reliable delivery.

I also explore Go, messaging systems, and AI-powered integrations through personal projects.

AI tools are part of my engineering workflow. I use **Claude Code**, **Cursor**, and **ChatGPT** to explore codebases, compare implementation approaches, plan technical work, support refactoring, draft tests, and improve documentation.

I treat generated output as a starting point, not as a source of truth: I review the code, validate behavior, run tests, and remain responsible for the final technical decisions.

## Selected work

### [hernani.dev](https://hernani.dev/en/)

My bilingual (PT-BR/EN) portfolio and technical writing site, built as a small production project:

- Astro static output, TypeScript, and Tailwind CSS, deployed on Cloudflare Workers Static Assets.
- Pull-request validation with GitHub Actions: type checks, build, tests over the generated pages, and accessibility and Lighthouse audits.
- Technical SEO: canonical and `hreflang` alternates, structured data, sitemap, and RSS feeds per locale.
- Security headers and a Content Security Policy, with a Git-based CMS (Decap) restricted to the writing section.
- CV pages and PDFs generated from the same data modules as the site.

### [Talk BH](https://talk.bh/)

A bilingual website for an independent English-conversation community in Belo Horizonte.

I developed and maintain the website and its technical delivery workflow:

- Astro, TypeScript, and Tailwind CSS.
- A content workflow designed to let organizers update community information without editing application code.
- Build validation with GitHub Actions and static deployment on Cloudflare Workers.
- Responsive pages, localized content, and technical SEO.

The community organizers are responsible for the meetups and their content; my contribution is the website and its technical infrastructure.

### [BV Tintas](https://bv-tintas.pages.dev/)

A website for an automotive paint store in Contagem, open since 2009, serving professional refinishers and people doing small repairs on their own cars.

I developed and published the website:

- A five-page static site built with Astro, strict TypeScript, and native CSS, with JavaScript in the browser only for the accessible mobile menu.
- Phone numbers, address, and services in one typed module used by every page and by the `Store` structured data.
- Deployment on Cloudflare Pages with a preview for each pull request; GitHub Actions runs the checks.
- Context-specific WhatsApp calls to action, Open Graph, and copy limited to what the store has confirmed.

The store defines its products, services, and business information; my contribution is the website development and its publication.
